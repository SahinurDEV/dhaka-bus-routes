# ঢাকা বাস রুট ও ভাড়া (Dhaka Bus Routes)

Static Bengali web app: enter start/destination (Bengali or English autocomplete), see direct buses and estimated fare (BRTA ~Tk 2.45/km, min Tk 10). Route data from community sources (see SOURCES.md); fares and coordinates are estimates.

Live: https://sahinurdev.github.io/dhaka-bus-routes/
